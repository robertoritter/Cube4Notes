# Host desktop

Um aplicativo desktop opcional pode abrir ou hospedar a experiência web, mas não é o conceito central do produto. O primeiro `.exe` referido na exploração é o processo Cube4Notes Server que inicia o servidor web; o usuário trabalha pela interface de navegador. O servidor pode rodar no próprio computador do usuário ou num servidor doméstico (Debian, no cenário de referência). Formatos exatos de distribuição continuam pendentes; builds para macOS precisam funcionar via CI porque não há ambiente macOS local neste cenário.
